Le score ne compare pas position par position : il compte le plus long enchaînement d'items déjà dans le bon ordre relatif. Un seul item mal placé (ex: 1-3-4-5-6-2 au lieu de 1-2-3-4-5-6) ne fait perdre des points que pour cet item-là, pas pour toute la liste.

Le passage à la question suivante reste toujours manuel sur cette manche (bouton "Question suivante") : le classement de chacun (ou de chaque équipe) reste affiché le temps que tu veux avant de continuer.

Le type de contenu (texte, image ou son) se choisit question par question, pas ici — tu peux donc mélanger dans une même manche une liste à réordonner en texte, puis une en images, etc.
